4. DOCKER & KAFKA COMMON TROUBLESHOOTING (गाडी अडकल्यास काय करावे?)
-------------------------------------------------------------------
A] Kafka Connection Error (Repeated connection failure logs):
   -> Reason: Your Notification-Service is up, but Kafka Broker container is down.
   -> Fix: Check Docker Desktop if the Kafka container is 'Running' or 'Exited'.

B] Zipkin Integration Failure (Missing Traces):
   -> Reason: Sleuth/Micrometer is sending traces to the wrong port, or Zipkin 
      is running inside Docker network and cannot see your local Java app.
   -> Fix: Ensure 'spring.zipkin.base-url=http://localhost:9411/' is present 
      in all microservices' application.yml files.

C] Docker Out of Memory / Slow Down:
   -> Even with 16GB RAM, sometimes Docker resource allocation limits are low.
   -> Fix: Go to Docker Desktop Settings -> Resources -> Ensure at least 4GB to 6GB 
      RAM and 3-4 CPUs are allocated to Docker.

5. INTERVIEW QUICK ANSWERS (हा प्रोजेक्ट इंटरव्ह्यूमध्ये कसा सांगायचा?)
-----------------------------------------------------------------------
* Why Spring Cloud Gateway? 
  -> It acts as a single entry point, handles global routing, and validates 
     JWT tokens before forwarding requests downstream.
* Why Kafka for Notification Service?
  -> Asynchronous decoupling. Order service places the order immediately and 
     pushes an event to Kafka. Notification service reads it whenever free.
* Why Zipkin?
  -> For Distributed Tracing. It helps track a unique request ID across multiple 
     microservices to debug which service is causing latency or failure.
